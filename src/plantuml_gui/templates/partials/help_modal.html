Build diagrams by working on the picture itself: right-click an element to add something next to it, and double-click it to change its text. The PlantUML code on the left is written for you, and you can edit it directly at any time. Code and diagram always stay in sync.

Activity diagrams
  1. Add a step. Right-click an activity and choose Add Below › Activity.
  2. Name it. Double-click the new activity, type its text and press Submit or Ctrl+Enter.
  3. Add a decision. Choose Add Below › If Statement, then double-click it to enter the condition and the label of each branch.
  4. Find the code. Hover any element: its line is highlighted in the editor.
Sequence diagrams
  1. Add a participant. Right-click a participant's box and choose Add Participant; it appears to the right. Right-click it again and choose Rename.
  2. Draw a message. Right-click a lifeline at the height the message should go and choose Add Message. An arrow follows the mouse: click the receiving lifeline and type the message text.
  3. Group messages. Right-click where the group should start, choose Add Group and a type such as loop, then click where it should end and give it a label.
  4. Find the code. Hover a message, participant, note or group: its line is highlighted in the editor.
Try it yourself: open New › Activity Demo or New › Sequence Demo for a ready-made diagram to experiment on. Made a mistake? Ctrl+Z undoes it. To share your diagram, copy the URL in the address bar.
Mouse and keyboard actions
Editing
Right-click an elementOpen its menu: add, edit or delete
Double-click an elementEdit its text
Ctrl+EnterSubmit the text you are editing
Clear the text of a title, note, group or boxDelete that element
Ctrl+Z / Ctrl+YUndo / redo
Moving around
Left-click and drag the diagramPan
Mouse wheel or touchpad pinchZoom
Code and diagram
Hover an elementHighlight its line in the editor
Hover or click a line in the editorHighlight its element in the diagram
Sharing
Copy the URL in the address barShare the diagram: the URL contains it
